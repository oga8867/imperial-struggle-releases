An unofficial digital adaptation of GMT Games' Imperial Struggle, with English and Korean interfaces. Play solo against AI, locally with two players, or online with the room creator's PC hosting the match.

## Get started

1. Download the Windows x64 Portable ZIP or Setup.exe from the latest release.
2. For the ZIP, extract the entire folder and run ImperialStruggle.exe. Keep the PCK and licenses beside it. For Setup.exe, run the installer and launch the game from the Start menu.
3. Choose English or Korean in Settings. The main menu footer shows your game version.
4. Choose solo Britain/France, local two-player play, or Online. Both online players should use the same release.

Godot, Steam and separate Korean fonts are not required. The game targets 64-bit Windows 10/11 and OpenGL 3.3 graphics. For file verification, use the release's SHA256SUMS.txt.

## 실행 방법

1. 최신 릴리스에서 Windows x64 Portable.zip 또는 Setup.exe를 받습니다.
2. ZIP은 전체 압축을 풀고 ImperialStruggle.exe를 실행합니다. 옆의 PCK·이용 조건 폴더도 함께 둡니다. 설치파일은 실행 후 시작 메뉴에서 게임을 엽니다.

4. 혼자 영국/프랑스, 로컬 2인, 온라인 중 원하는 방식을 선택합니다. 온라인 상대도 같은 버전을 사용하세요.

Godot·Steam·별도 한글 글꼴 설치는 필요 없습니다. Windows10/11 64비트와 OpenGL3.3 그래픽을 기준으로 만들었습니다. 파일 확인은 릴리스의 SHA256SUMS.txt를 이용하세요.

## What is included / 포함 기능

- Original map/component artwork with a paper and ink interface; readable resources, rewards and Ministry keywords.
- Named saves, quick save, dated play logs, keyboard controls and full card-effect inspection.
- Peace/War progression, theater strength and reward explanations, and separate confirmation for map/War choices.
- Basic or strategic AI; optional observation of one action at a time, map highlights and public card artwork.
- Host-based IP/invitation-code online play, UPnP attempt, reconnect/resume and consent-based safe undo.

- 원작 지도·구성물과 종이·잉크 UI, 주요 자원·승점계산·내각 키워드 표시.
- 이름별 저장·빠른 저장, 날짜별 기록, 단축키, 카드 전체 효과 보기.
- 평화/전쟁 진행, 전장별 전력·보상 설명, 지도·전쟁 선택 후 별도 확정.
- 기본/전략 AI, 선택 가능한 행동별 연출·지도 강조·공개 카드 표시.
- IP/초대 코드 접속, 자동 포트 열기 시도, 재접속·저장 재개, 상대 동의가 필요한 안전한 되돌리기.

AI uses heuristics and a limited search. Expert-level strength or optimal play is not established. AI는 평가 기준과 제한된 탐색을 사용하며 최적 플레이나 숙련자 수준을 보장하지 않습니다.
